# 保卫胖宝（原型 v0.1）
像王权陨落的网页塔防：鸡毛/小白白天建造，晚上亲自上场，保护家里的胖宝。纯 HTML + Canvas 2D，无框架。
- `js/data.js` 武器/天赋/建筑/敌人/地图/每晚出怪
- `js/game.js` 模拟（状态在 `G`，玩家按 id 存在 `G.players`，以后可接 Supabase 双人）+ 画面
- `js/ui.js` 开始界面、HUD、按钮、摇杆、键盘
- `js/sprites.js` 来自《我们的小岛》的小狗/房子/树等画法

## v0.2（自检优化）

城墙中间是门（自己人能过、敌人不能）、敌人会绕开塔/兵营/菜园（大笨熊照样砸）、伤害数字、金币飞进钱包、受击震屏、
横屏镜头偏向家、挑战天赋真正变难（敌人更多更强、金币只 ×1.25）、HUD 只在变化时更新、树木预渲染。

## v0.3
- 所有建筑（城墙、弹弓塔、营地、菜园、家）都会被敌人攻击；路过附近的敌人会先拆建筑，被拆掉的当晚不能用，第二天早上自动修好；受伤建筑显示血条。
- 小兵指令：「🐾 跟随」跟着狗狗走；「🚩 原地部署」守在按下的位置（地上插小红旗）。默认在营地旁部署；新招的小兵直接去当前集合点。键盘 F 切换。
- 左上角小地图：家、狗狗、建筑、小兵、敌人（红点）。白天红色箭头闪烁提示今晚敌人方向；夜里屏幕边缘红箭头指向画面外的敌人。点小地图可放大/缩小。

## v0.4（自测修正）
- 修正：天亮时如果正在挥武器/放技能，狗狗会一直卡在攻击姿势。
- 修正：玩家贴着弹弓塔/营地/菜园走会被卡住，现在会顺着边绕过去。
- 抱武器动画：挥砍起手不再挡脸；旋风锅铲改成左右转身平举锅铲；震地一击改成侧身举高再砸地；满天飞盘双爪举高。
- 界面：顶部提示条放到 HUD 下、小地图右边，不再挤成 4 行的窄条，也不和弹出提示重叠；小地图放大时提示会让开，横屏放大不会盖住摇杆。
- 横屏开始界面改成左右两栏，不用滚动就能点「出发」。
- 夜里屏幕边缘的红箭头不会被顶部提示挡住；暂停页键盘说明改为「F 跟随/部署」。
- 离线缓存：安装时先缓存核心文件，第一次打开后断网也能玩；换新版本时自动删除旧缓存。（改版本时 sw.js 里的 V 要和 index.html 的 ?v= 一致）
