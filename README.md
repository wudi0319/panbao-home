# 保卫胖宝（v0.6）
像王权陨落的网页塔防：鸡毛/小白白天建造，晚上亲自上场，保护家里的胖宝。纯 HTML + Canvas 2D，无框架。
- `js/data.js` 武器/天赋/建筑/敌人/地图/每晚出怪
- `js/game.js` 模拟（状态在 `G`，玩家按 id 存在 `G.players`，以后可接 Supabase 双人）+ 画面
- `js/ui.js` 开始界面、HUD、按钮、摇杆、键盘
- `js/sprites.js` 来自《我们的小岛》的小狗/房子/树等画法

## v0.3
- 所有建筑（城墙、弹弓塔、营地、菜园、家）都会被敌人攻击；路过附近的敌人会先拆建筑，被拆掉的当晚不能用，第二天早上自动修好；受伤建筑显示血条。
- 小兵指令：「🐾 跟随」跟着狗狗走；「🚩 原地部署」守在按下的位置（地上插小红旗）。默认在营地旁部署；新招的小兵直接去当前集合点。键盘 F 切换。

## v0.5（围墙连成一圈）
- 第一关「胖宝的院子」：原来四段互不相连的短墙，改成 8 段可分别建造的围墙。四边路上各有一座城门，四个角落是 L 形墙，全部建好后能围成一圈，接缝连在一起。
- 自己和小动物可以从城门进出，敌人只能破墙或从缺口绕进去。敌人会寻路：有缺口就走缺口，围死了就打最近的墙。
- 墙的布局按地图写在数据里，方便以后加新关。通关后解锁第二关「瓮城」：南门外有一圈大门错开的瓮城，西南菜园单独围起来。
- 小地图会画出整圈围墙和门洞。围墙每段 3 金币，几天内可以围满，不影响原来的建造节奏。

## v0.6（多关卡）
- 一共 6 关，通关上一关才能解锁下一关。开始页是 3×2 的关卡格子，已通关打 ★，没解锁是 🔒。以前通关过的进度还在，瓮城照样解锁。
- 里外花园：里外两圈围墙，外门和内门错开。
- 小石桥：南边一条小河，三座石桥是必经之路，桥上可以建门。
- 四面花田：四个角落的菜园各自围起来，敌人会早点从四面过来。
- 盘山公路（最后一关，最难）：悬崖盘道，胖宝住在山顶。沿路有四道关卡，每道都有城门和建塔的台地，可以一层一层守、守不住就往上撤。敌人只会沿公路往上爬，悬崖下不去。
- 地形：河、桥、悬崖和路会挡住走路和寻路；小地图也会画出来。

## v0.7（星星、加成和升级老家）
- 通关按守得怎么样评 1–3 星（通关、家还剩多少血、建筑有没有被打坏），再叠上开局选的挑战星，最多 5 星。每关记下最高星。可花的星星 = 各关最高星加起来，减去已经拿去兑换加成的。同一关只有刷出更高星才会再攒到新的。
- 原来的天赋并进「加成 / 挑战」：出发前先进入准备页，用星星兑换并最多带 3 个加成；挑战免费，增加难度也增加通关星数。更强的加成就和挑战要通关指定关卡或攒到一定星数才解锁。
- 局内可以升级老家，最多 3 次。白天走到家旁边，花金币从 3 个加成里选 1 个。屋顶上会亮星。
- 以前通关过的关会记 1 星，守过第 3 夜的会自动拥有「坚固的家」。

## v0.9
- 建造和每次升级（1 / 2 / 3 级）都会弹出两个路线，选一个再生效。小猫营、小鸭营和城墙、弹弓塔、菜园、胖宝奶瓶都是同一套「每级二选一」。
- 弹弓塔：连珠（3 发分打，每发 55%）或炸弹（落地溅射）；加伤或射程；减速或穿透（炸弹则炸得更开）。
- 兵营：人海（多 1 只、复活更快）或精兵（血 +30%、攻 +25%）；再招募或狠打；急速复活或铁军。
- 菜园：丰收 / 聚宝（附近击杀加金）；沃土 / 拾荒；粮仓 / 财神。
- 城墙和门：铁壁（生命）或荆棘（反伤）；加固或尖刺；堡垒（更厚还带护甲）或反噬（反伤并能顿一下敌人）。
- 升级老家时先给奶瓶选一条路，再选原来的家园加成：连发或奶粉炸弹；快手或远投；加料或黏稠。
- 路线加强后，全体敌人的血量和攻击提高 10%。
